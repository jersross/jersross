## Deployed Applications

### Airbnb Arbitrage Profitability Analytics — Gradio App
Consulting-style engagement for a hypothetical NYC Airbnb rental arbitrage operator seeking to identify apartments capable of clearing a $120/night profitability threshold before signing a lease. Includes a robust data validation and cleaning pipeline, exploratory analysis of pricing drivers (borough, reviews, availability, minimum nights), and a Multiple Linear Regression model evaluated with R²/Adjusted R² and interpreted via standardized coefficients. Delivered as a two-tab Gradio application: a Market Dashboard with interactive filters and KPIs, and a Prediction Simulator that estimates nightly price for a candidate listing, flags it above/below threshold, and gives a plain-language, confidence-scored recommendation.
**Skills:** Python · Pandas · scikit-learn (Multiple Linear Regression) · Matplotlib/Seaborn · Gradio
[![View Project](https://img.shields.io/badge/View_Project-1a1a2e?style=for-the-badge)](https://github.com/jersross/airbnb-arbitrage-analytics)

### NovaRetail Analytical Dashboard
Interactive customer intelligence dashboard built entirely with AI-assisted tooling. Surfaces revenue drivers and at-risk customer segments through KPI, filtering, and visualization layers, deployed via Streamlit Community Cloud with GitHub-based CI/CD.
**Skills:** Python · Pandas · Plotly · Streamlit · Bash · Git
[![View Project](https://img.shields.io/badge/View_Project-1a1a2e?style=for-the-badge)](https://github.com/jersross/novaretail-dashboard/)

### IBM HR Analytics Application
Unsupervised K-Means segmentation of IBM's HR workforce (1,470 employees), including model evaluation (elbow method, silhouette score) and business-labeled cluster profiling. Packaged as an interactive Gradio dashboard with a scenario simulator for hypothetical-employee attrition risk and retention planning.
**Skills:** Python · scikit-learn · K-Means Clustering · Gradio
